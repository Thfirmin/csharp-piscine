# csharp-piscine

A collection of exercises for learning and mastering the C# programming language

---

## 📘 Progressive C# Exercises Track


### **Level 0 – Warm-up (Syntax and Console)**

* **Ex00 – Hello World** → Write a program that prints "Hello, Wordl!".
* **Ex01 – Basic operations** → Ask for two integers and show addition, subtraction, multiplication, and division.
* **Ex02 – Multiplication Table** → Given a number `n`, print its multiplication table from 1 to 10.
* **Ex03 – Type Conversion** → Read a string and try to convert it to `int` with `int.TryParse`.
* **Ex04 – Conditions** → given a number, say whether it is even or odd.
* **Ex05 – Loops** → print all prime numbers from 1 to 100.

---

### **Level 1 – Functions and Strings**

* **Ex06 – Mathematical functions** → Implement `Factorial(int n)` and `Fibonacci(int n)`.
* **Ex07 – String manipulation** → Implement functions such as:

  * `StrLen(string s)` → returns the length.
  * `StrRev(string s)` → returns the reversed string.
  * `IsPalindrome(string s)` → checks if it is a palindrome.
* **Ex08 – Basic Arrays** → create functions to find the **minimum, maximum, and average** of an array.
* **Ex09 – Search** → implement a linear search and then a binary search in a sorted array.

---

### **Level 2 – Structures and Classes**

* **Ex10 – Point Structure** → create a `struct Point { int X, Y }` and calculate the distance between two points.
* **Ex11 – Bank Account Class** → implement `Account` with balance, `Deposit`, `Withdraw`, and `Transfer` methods.
* **Ex12 – Rectangle Class** → with `Width`, `Height` properties, and `Area()` method.
* **Ex13 – Simple Inventory** → create a `List<Item>` where `Item` has a name and quantity.

---

### **Level 3 – Collections and Algorithms**

* **Ex14 – Sorting** → implement BubbleSort, then `CompareTo` with `List.Sort()`.
* **Ex15 – Dictionary** → create a dictionary of contacts (name → phone number).
* **Ex16 – Word count** → given a text, count how many times each word appears.
* **Ex17 – Calendar** → class that allows you to add, search, and remove appointments by date.

---

### **Level 4 – Advanced OOP**

* **Ex18 – Inheritance** → `Animal` with subclasses `Dog` and `Cat`, each with `EmitSound()`.
* **Ex19 – Interface** → `IShape` with method `Area()`, implemented by `Square` and `Circle`.
* **Ex20 – Polymorphism** → list of different geometric shapes and total area calculation.
* **Ex21 – User System** → with simple authentication (login/password).

---

### **Level 5 – File Manipulation**

* **Ex22 – Read/Write text file** → program that reads and prints the contents of a `.txt` file.
* **Ex23 – Log Record** → each program execution saves the date/time in a file.
* **Ex24 – CSV Parser** → read a CSV file of students (name, grade) and calculate the average.
* **Ex25 – Mini Database** → manage data in JSON with `System.Text.Json`.

---

### **Level 6 – Larger Projects**

* **Proj01 – MiniShell C#** → implement a simple command interpreter (`cd`, `ls`, `echo`).
* **Proj02 – TCP Chat** → create a TCP server/client for console chat.
* **Proj03 – Persistent Calendar** → calendar that saves and loads appointments from a JSON file.
* **Proj04 – Mini Console Game** → 42's **so_long** style: player moves on a grid (`WASD`), collects items, and exits through the door.
* **Proj05 – REST API** → with ASP.NET minimal API to manage task list (CRUD).

---

👉 This track keeps exercises practical, with challenges that gradually evolve until you reach **networks, systems, and the web** in C#.
